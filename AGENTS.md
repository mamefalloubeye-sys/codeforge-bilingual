# Project Instructions - CodeTrainer Pro Ultimate

## Project Overview

CodeTrainer Pro Ultimate is a bilingual (French/English) programming learning platform built with React, TypeScript, Vite, Tailwind CSS and shadcn/ui.

The application provides:
- Interactive programming exercises
- Code editor integration
- Learning progress tracking
- Tutorials and challenges
- Bilingual user interface

## Technology Stack

Frontend:
- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Radix UI
- Monaco Editor

Testing:
- Vitest
- Testing Library

## Development Rules

Before modifying code:
1. Analyze the existing architecture.
2. Explain the proposed changes.
3. Avoid unnecessary refactoring.

When writing code:
- Follow existing TypeScript conventions.
- Keep components modular.
- Prefer reusable components.
- Maintain clean and readable code.
- Preserve existing features.

## Important Constraints

- This project is currently frontend-only.
- Do not introduce a backend without discussion.
- Do not replace existing libraries without justification.
- Respect the current folder organization.

## Workflow

For every task:
1. Understand the objective.
2. Inspect relevant files.
3. Explain the solution.
4. Implement changes carefully.
5. Verify that the application still works.
