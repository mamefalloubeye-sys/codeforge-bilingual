# CodeTrainer Pro Ultimate 🚀

A bilingual interactive coding learning platform built with React, TypeScript, Monaco Editor and Tailwind CSS.

CodeTrainer Pro Ultimate helps developers learn programming through:

- Interactive coding exercises
- Real-time code editor experience
- Progress tracking
- Bilingual interface (French / English)
- Multiple programming languages support

## ✨ Features

- 🖥️ Monaco Editor integration
- 🌍 French / English localization
- 📚 Interactive programming exercises
- 📊 Learning progress tracking
- 🎯 Challenges and tutorials
- 🎨 Modern UI with shadcn/ui and Tailwind CSS

## 🛠️ Tech Stack

Frontend:

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Radix UI
- Monaco Editor
- Framer Motion

Testing:

- Vitest
- Testing Library
